Agentic Developer Handbook

A Java-first, open-source handbook for understanding and building agentic systems — one concept at a time, each with a small runnable Java lab and an honest answer to "when should I not use this?"

It is not an agent framework, a library catalog, or a skill marketplace.

The learning path

  1. Model
  2. Structured Output
  3. Tools
  4. Knowledge / RAG
  5. Memory
  6. Skills
  7. Agent Runtime

You probably don't need all of these.

The path is for learning, not a mandatory architecture: stop when the problem is solved. A single LLM call is not an agent, and a database lookup does not become RAG because the application also calls a model.

2 Decide what architecture the problem deserves

Agentic System Readiness Assessment

Bring your own use case. A fixed order of questions, starting with "could ordinary software do this?", helps you find the smallest architecture it needs — often no agent, and sometimes no model at all. Not a score; it exports an ASSESSMENT.md.

Good to know

  • Available today: Labs 01–07, Capstone 01, and the readiness assessment. MCP, evaluation, observability, security, and deployment are on the roadmap and not implemented yet.
  • Your answers stay in your browser. The interactive pages have no backend, no accounts, no analytics, and no cookies; progress is saved only in this browser's local storage.
  • Open source under the Apache License 2.0. Corrections, learning feedback, and proposals are welcome — see how to contribute.
